# AWS RDS Instance Module

**Status**: 🚧 Coming Soon

## Planned Features

- ✅ Multi-engine support (MySQL, PostgreSQL, MariaDB)
- ✅ Storage auto-scaling
- ✅ Automated backups
- ✅ Multi-AZ deployment
- ✅ Parameter groups
- ✅ Security group management
- ✅ Monitoring and alerts

## Roadmap

This module is planned for **Q1 2026** as part of the AWS module expansion.

For now, you can use AWS RDS directly in your stacks or use the official AWS provider modules.

## Cost

**Pay-as-you-go** ⚠️

- **db.t3.micro**: ~$15/month (minimum)
- **Storage**: $0.10/GB/month
- **Free Tier**: 750 hours of db.t2.micro, 20GB storage ✅
