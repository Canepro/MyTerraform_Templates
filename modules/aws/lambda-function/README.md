# AWS Lambda Function Module

**Status**: 🚧 Coming Soon

## Planned Features

- ✅ Function deployment with zip files or Docker
- ✅ Lambda layers support
- ✅ Environment variables and secrets
- ✅ VPC configuration
- ✅ Dead Letter Queues
- ✅ CloudWatch Logging
- ✅ IAM role management
- ✅ Event triggers (API Gateway, S3, SQS, etc.)

## Roadmap

This module is planned for **Q1 2026** as part of the AWS module expansion.

For now, you can use AWS Lambda directly in your stacks or use the official AWS provider modules.

## Cost

**Pay-per-request** ⚠️

- **Free Tier**: 1M requests/month ✅
- **Cost**: $0.20 per 1M requests after free tier
- **Compute**: $0.0000166667 per GB-second
