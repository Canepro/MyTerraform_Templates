# AWS EKS Cluster Module

**Status**: 🚧 Coming Soon

## Planned Features

- ✅ Managed Kubernetes cluster
- ✅ Node groups (managed and self-managed)
- ✅ Add-ons support (VPC CNI, CoreDNS, etc.)
- ✅ IAM OIDC provider
- ✅ Cluster autoscaler
- ✅ Security groups and networking

## Roadmap

This module is planned for **Q1 2026** as part of the AWS module expansion.

For now, you can use AWS EKS directly in your stacks or use the official AWS provider modules.
